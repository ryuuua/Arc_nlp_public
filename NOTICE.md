# Solver notice

This distribution contains the portable Standard projected-gradient
archetypal-analysis solvers v2, v3 and v4, their supporting stopping policy and
Torch runtime helper, and a standalone fitting interface. The original v2
source is preserved for reproducibility; v3/v4 source fingerprints are recorded
in `provenance/source_fingerprints.json`. Robust, scalable, Mahalanobis and other
exploratory solvers are not included.

No model weights or dataset contents are redistributed by this repository.

The research website and its API excerpts are built from the files explicitly
listed in this repository's `docs/site/site.json`. Broader research directions
described on the website do not imply those implementations are distributed.

No independent open-source license has been specified for this project. Public
visibility does not grant additional license permissions. Dependencies retain
their own licenses; no dependency source or binary is vendored here.
